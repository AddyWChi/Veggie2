## Install Vue.js and Create a Project
This project uses Vue 2.

URL: [https://v2.vuejs.org/v2/guide/installation#NPM](https://v2.vuejs.org/v2/guide/installation#NPM)
URL: [https://cli.vuejs.org/#getting-started](https://cli.vuejs.org/#getting-started)

#### Install NPM
```
# Use Vue version 2.7.16
$ npm install vue@^2
```

#### Install Vue CLI 
```
npm install -g @vue/cli
```
This will create following:
[node_modules]  
package-lock.json  
package.json  

#### Create project
```
vue create my-project
```
- This will create a folder 'my-project' under current folder.
- Select to use Vue2.

This will create following:
[node_modules]  
package-lock.json  
package.json  
[my-project]    


## Install Bootstrap for Vue
